# Challenge FAQ Answers

*Source: DEV HF26 hub FAQ (dev.to/challenges/hf26), fetched Oct 6, 2026.*

1. **Old projects:** NOT allowed. Submission AND repo must be started and completed inside the challenge window (Week 1: Oct 5–11, 2026). PRs to existing projects do not count. Riffing on open-source code is fine if changes are significant and all non-trivial third-party work is credited.
2. **Commits after the deadline:** Must be explicitly noted in the README, otherwise the entry risks disqualification.
3. **Submissions:** One per challenge (up to five across October). Each must be a NEW project built in that challenge's window (Grassdex cannot be reused for Week 2). A submission can win once.
4. **Partner categories:** Opt in by using the partner's technology AND listing each category in a "Prize Categories" section of the DEV post. One project can enter every category it genuinely uses. No partner tech is required for the overall prize. Best Use of Gemma ($200): run Gemma locally, fine-tune it, or serve it elsewhere.
5. **Other rules:**
   - AI use is permitted (with disclosure).
   - English is required for prize eligibility.
   - Age 18+.
   - Embedding an agent session is optional.
   - Ties broken by the entry with more positive community reactions.
   - Writing quality matters most in scoring.
